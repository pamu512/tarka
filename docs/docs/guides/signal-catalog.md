# Signal catalog: SDK field → rule key → pack snippet

Every signal the SDKs collect, the tag it mints on the decision receipt, and a
copy-paste pack snippet that consumes it. This is the contract between the
client SDKs and the rule packs - if a field appears here, a rule can consume it
today; if it is not here, no rule sees it.

Sources of truth: `packages/fraud-sdk-typescript/src/behavior.ts` (signal
extraction), `decision_api/main.py::extract_behavior_tags` (tag minting),
`rules/*.json` (consumption). This page is regenerated by hand when any of the
three change - a drifted row is a bug.

## Device signals (all SDKs)

Flat booleans and strings from the device context. Rules consume them directly
by field name (`when` conditions), no tag minting needed.

| SDK field | Type | Meaning | Example pack rule |
|---|---|---|---|
| `is_vpn` | bool | VPN detected | `{"op": "is_true", "field": "is_vpn"}` |
| `is_emulator` | bool | Emulator / simulator | `{"op": "is_true", "field": "is_emulator"}` |
| `is_bot` | bool | Bot indicator (SDK heuristics) | `{"op": "is_true", "field": "is_bot"}` |
| `is_new_device` | bool | First-seen device for entity | `{"op": "is_true", "field": "is_new_device"}` |
| `webdriver_detected` | bool | Selenium/Playwright-class driver | `{"op": "is_true", "field": "webdriver_detected"}` |
| `headless_detected` | bool | Headless browser | `{"op": "is_true", "field": "headless_detected"}` |
| `automation_detected` | bool | Automation framework | `{"op": "is_true", "field": "automation_detected"}` |
| `mock_location_detected` | bool | Mocked geolocation | `{"op": "is_true", "field": "mock_location_detected"}` |

## Behavior signals (web / TS SDK, sealed packet)

The `BehaviorCollector` samples typing, mouse, scroll, touch, and session
cadence. Raw arrays stay client-side; only the derived summary ships in the
sealed behavior packet. The evaluate pipeline reduces them to **behavior
tags** on the receipt - packs consume the tags, never the raw arrays.

| SDK summary field | Receipt tag | Trips when |
|---|---|---|
| `bot_indicators.zero_mouse_movement` | `behavior:no_mouse` | zero pointer movement in window |
| `bot_indicators.constant_typing_speed` | `behavior:constant_typing` | typing cadence std-dev ~0 |
| `bot_indicators.no_scroll` | `behavior:no_scroll` | no scroll events in window |
| `bot_indicators.suspiciously_fast` | `behavior:fast_typing` | superhuman inter-key speed |
| `typing.hesitation_events_gt_500ms` | (raw; feeds hesitation models) | human-pause count |
| `session.paste_count > 3` | `behavior:heavy_paste` | form largely pasted |
| `session.tab_switches > 10` | `behavior:excessive_tab_switch` | disengagement / parallel sessions |
| `typing.avg_inter_key_ms < 25 and key_count > 30` | `behavior:superhuman_typing` | inhuman consistent speed |

### Example: consume behavior tags in a pack (tag_rules)

```json
{
  "id": "behavior_bot_stack",
  "any_tag": ["behavior:no_mouse", "behavior:constant_typing", "behavior:superhuman_typing"],
  "tags": ["behavior:challenger_bot_stack"],
  "score_delta": 18,
  "description": "Bot-indicator stack - shadow evidence only"
}
```

A complete shipped example lives in `rules/behavior_challenger_v1.json`
(mode `shadow` - Observe-only; a human promotes it or it never decides).

## What is deliberately NOT here

- No third-party fingerprint SDKs (no named vendors - native entropy only).
- No raw keystroke/mouse arrays cross the wire - only derived summaries in a
  sealed packet.
- Signals never pool across tenants; each tenant's receipts are its own.
