## Ingress reliability scorecards (MVP)

Aligned with Day 60: *“Integration reliability panel flags degraded connectors with actionable remediation.”*

| Item | May 30 bar | Owner signal |
|------|------------|--------------|
| **API shape** | `GET /v1/integrations/scorecards?tenant_id=` returns `overall_score`, per-provider `status`, `provider_score`, `latency_ms`, `reasons`, **`last_checked_at`** | Contract test |
| **SLA fields** | Top-level **`sla`**: `availability_target_pct`, `latency_target_ms_p95`, **`trend_window_days`** (label for snapshot window, not a time-series DB) | JSON + OpenAPI note |
